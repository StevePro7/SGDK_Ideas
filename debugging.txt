Retro indie game development - for Sega Master System debugging source code we can use Emulicious emulator which has tiles, tileset, palette viewers plus there is a VS Code extension for Emulicious that we can use to remote debug the emulator and debug step thru the code.  Question: is there a similar emulator and VS Code extension for debugging Sega Genesis / MegaDrive?


Yes — the Sega Genesis / Mega Drive has a very similar development and debugging setup, and there is a particularly good option if you want the same workflow you have with Emulicious on the Master System.

My first recommendation would be BlastEm + VS Code + SGDK + GDB. BlastEm supports source-level debugging through GDB, breakpoints and single-stepping, as well as graphical debugging tools for the Genesis video hardware. The main difference is that the VS Code integration is generally configured through GDB rather than using the Emulicious-specific debugger extension.

What about the tile and palette viewers?

This is an important distinction if you're used to Emulicious.

Debugging feature				Genesis option
Source-level stepping and breakpoints		BlastEm + GDB + VS Code
CPU registers and memory			BlastEm debugger / GDB
Tile graphics in VRAM				BlastEm VRAM viewer
Palette inspection				BlastEm CRAM viewer
Background plane inspection			BlastEm plane viewer
Combined background composition			BlastEm plane-composition debugger
	



BlastEm provides these graphics debugging facilities alongside its CPU debugger.

The Genesis hardware does work differently from the Master System: the video display processor has its own VRAM, CRAM palette memory and scrolling planes. So you'll be inspecting different hardware structures, even though the debugging workflow is familiar.
